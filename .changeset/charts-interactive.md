`Chart.Tooltip`: a tooltip per category with every series' value, rendered on the server and shown on hover with CSS alone. `Chart.Legend interactive`: legend entries become toggles that fade a series out and back — the chart's only client component, a thin layer that marks the server-rendered marks as muted, so the stacks and the scale hold still. New tokens `--chart-hover`, `--chart-tip-bg`, `--chart-tip-border`, `--chart-tip-shadow` and `--chart-muted-opacity`.
